# Форма обратной связи

Тестовое задание для вакансии PHP-разработчика (Middle/Senior).

## Задача

Разработать форму обратной связи с клиентской и серверной валидацией,
отправкой уведомления на email и защитой от спама с помощью captcha.

Форма должна содержать:

- скрытое поле со значением `message`;
- тему обращения;
- ФИО;
- телефон;
- email;
- сообщение;
- captcha;
- согласие на обработку персональных данных;
- кнопку отправки.

Все поля обязательны. Клиентская часть должна проверять заполнение, форматы имени, телефона и email, а также ограничения длины. Серверный PHP-обработчик должен повторять проверки, проверять captcha, отправлять письмо и возвращать результат обработки.

Будут плюсом:

1. Отправка данных формы с использованием технологии AJAX.
2. Маска ввода на поле с номером телефона.
3. Авторская captcha по примеру.
4. Адаптивная вёрстка.

## Разработка

Для запуска нужен PHP 8.0 или новее.

Запустите встроенный веб-сервер из корня проекта:

```bash
php -S localhost:8000
```

После этого форма будет доступна по адресу <http://localhost:8000>. Адреса
получателя и отправителя задаются переменными окружения:

- `CONTACT_EMAIL` — адрес, на который приходят сообщения;
- `SENDER_EMAIL` — адрес отправителя в заголовке `From`.

Для обеих переменных по умолчанию используется `greggsoft@gmail.com`.

```bash
CONTACT_EMAIL=inbox@example.com \
SENDER_EMAIL=sender@example.com \
php -S localhost:8000
```

Для реальной отправки писем нужно настроить sendmail

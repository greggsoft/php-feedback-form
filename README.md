# Форма обратной связи — тестовое задание «ПрограмЛаб»

Тестовое задание для вакансии PHP-разработчика (Middle/Senior) в компании
«ПрограмЛаб».

## Задача

Разработать форму обратной связи с клиентской и серверной валидацией,
отправкой уведомления на email и защитой от спама с помощью captcha.

Форма должна содержать:

- скрытое поле со значением `message`;
- тему обращения;
- ФИО;
- телефон;
- email;
- сообщение;
- captcha;
- согласие на обработку персональных данных;
- кнопку отправки.

Все поля обязательны. Клиентская часть должна проверять заполнение, форматы
имени, телефона и email, а также ограничения длины. Серверный PHP-обработчик
должен повторять проверки, проверять captcha, отправлять письмо и возвращать
результат обработки.

Дополнительными преимуществами будут отправка через AJAX, модальное окно с
результатом, сборка с помощью Gulp и адаптивная вёрстка.

## Разработка

Структура проекта и команды запуска будут добавлены вместе с реализацией.
